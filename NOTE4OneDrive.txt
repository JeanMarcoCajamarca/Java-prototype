--> Description from Gemini concerning OneDrive and the errors I encountered:
" **OneDrive** is a cloud storage service built into Windows that automatically backs up folders like your Desktop and Documents to Microsoft's servers.
When Windows sets up OneDrive, 
it changes the actual physical folder paths on your hard drive to include the `OneDrive` folder wrapper (e.g., `C:\Users\Username\OneDrive\Desktop`), 
even though it still looks like your regular Desktop in File Explorer. Because your terminal starts in your base user profile folder by default, 
it couldn't find the `Desktop\Java projects` path directly without going through `OneDrive\` first. "
